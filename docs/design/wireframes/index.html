Low-fi wireframes

Design step 2 of scope §7.3 (issue #27): grey-box wireframes for every page in scope §7.2, plus login, "Kein Zugriff", the untracked empty state and the public privacy page. UI placeholder text is German; annotations (yellow boxes) are English. Plain HTML, CSS and a little vanilla JS: no build step, no server, no network requests.

Desktop: click a page name (opens full width; the drawer is persistent at ≥ 960px). Mobile: click 360px to load the page into the 360px frame (on the right on wide screens, below on narrow ones); the drawer becomes a hamburger menu. States: pages with several states have state links in their annotations box; the links below jump straight to a state.

Navigation

  • Admins (Administrator permission) see two drawer groups: Server (admin area) and Meine Statistik. Admin home is /admin.
  • Members (a Zugriffsrolle) see only Meine Statistik. Member home is /me.
  • Everyone else gets /kein-zugriff after login. /datenschutz needs no login.
  • Out of scope (scope §3): no web tracking toggle and no web delete; tracking changes only via /apollo commands.
