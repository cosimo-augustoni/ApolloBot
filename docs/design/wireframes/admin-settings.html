Einstellungen

Bootstrap-Modus

Es ist keine Tracking-Rolle festgelegt. Apollo erfasst zurzeit nur Mitglieder mit der Administrator-Berechtigung. Sobald du eine Rolle festlegst, endet der Bootstrap-Modus endgültig.

Apollo kann die Tracking-Rolle nicht vergeben

Die Rolle des Bots muss in der Rollenliste über «Statistik» stehen, und der Bot braucht die Berechtigung «Rollen verwalten». Solange das fehlt, funktionieren /apollo tracking on|off und /apollo privacy delete nicht.

Zurzeit wird niemand erfasst. Lege eine neue Tracking-Rolle fest.

Annotations

Page state: Eingerichtet Bootstrap-Modus Hierarchie-Warnung Rolle gelöscht
  • One tab per platform; each setting is stored per (guild, platform) (scope §5.1.2). The Fluxer tab has the same layout as Discord once the adapter exists.
  • Selectable roles come from the role sync. Options show role colour (swatch) and member count. Deleted roles are not offered; a deleted current role is shown as "(gelöscht)".
  • Live preview under each select ("X Mitglieder werden erfasst" / "X Mitglieder können sich anmelden") updates while picking, before saving. Changing the tracking role asks for confirmation when members would stop being tracked ("12 Mitglieder werden nicht mehr erfasst").
  • States: Bootstrap banner while no tracking role is set; hierarchy/permission warning when the bot lacks Manage Roles or sits below the tracking role (checked on page load); deleted-role warning (no Administrator fallback).
  • Changes apply without restart: the bot reloads role settings every 30 s. After saving show "Gespeichert. Gilt innerhalb von 30 Sekunden."
  • Admin access is not a setting (always the Administrator permission), so it does not appear here.
  • Change history: last 20 changes, newest first, with who and when.
