Page state: Erfasst Nicht mehr erfasst
  • Concept C · Bento: playful grid of tiles in different sizes. Every tile is tappable and opens a focused detail view (try the tiles).
  • Detail view: bottom sheet below 760px (drag handle, max 85% height), side panel from the right on desktop. Closes with ✕ or the backdrop (real page: also Escape and swipe down); the URL hash keeps it linkable.
  • Tile set: biggest number (messages) · top voice buddy · voice hours · active days · latest recap cover · heatmap teaser · top channel · favourite emoji (reactions) · games (bonus, hidden without data).
  • Tile order can be data-driven later (e.g. promote the tile with the most change), but starts fixed.
  • Desktop: 4 columns; phone: 2 columns, big tiles span both. Grid fills gaps densely.
  • State "Nicht mehr erfasst": the hint is a friendly in-content card (not a warning banner). Old data stays visible below it.
  • Member shell (all concepts): no drawer. Header = Apollo logo (home), period switch ("Oktober 2026 ▾": running month, past months/years, Benutzerdefiniert) and avatar menu (Privatsphäre, Datenschutz, Abmelden; "Admin" only for admins, leads to the existing admin shell).
  • Menus are <details> here so they work without JS; real pages use MudMenu.
  • Privatsphäre currently links to the existing me-privacy.html; it gets restyled to the chosen concept later.
