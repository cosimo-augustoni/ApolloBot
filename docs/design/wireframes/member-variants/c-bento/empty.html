Annotations

Page state: Nicht erfasst Bootstrap-Modus Erfasst, noch leer
  • Shown instead of the overview when the member has no stored data at all. A member who was tracked before sees their old data plus the friendly card (overview, state "Nicht mehr erfasst").
  • States: no tracking role ("Für dich werden keine Daten erfasst"), bootstrap mode, tracked but nothing recorded yet.
  • No web button to start tracking: only /apollo commands (scope §3, §5.4). The period switch is disabled here.
  • Bento look: one big tile instead of the grid.
  • Member shell (all concepts): no drawer. Header = Apollo logo (home), period switch ("Oktober 2026 ▾": running month, past months/years, Benutzerdefiniert) and avatar menu (Privatsphäre, Datenschutz, Abmelden; "Admin" only for admins, leads to the existing admin shell).
  • Menus are <details> here so they work without JS; real pages use MudMenu.
  • Privatsphäre currently links to the existing me-privacy.html; it gets restyled to the chosen concept later.
