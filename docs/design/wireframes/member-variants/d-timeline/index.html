Annotations

Page state: Erfasst Nicht mehr erfasst
  • Concept D · Timeline: vertical timeline by month, newest first. Scrolling down goes back in time.
  • The running month is expanded with the full stats (tiles, activity, channels, emojis, heatmap, games bonus). Older months are compact: 3 highlights and "Rückblick ansehen" when the snapshot exists.
  • Year separators link to the yearly recap. The sticky jump bar scrolls horizontally inside itself; selecting a period in the header switch scrolls to that month.
  • Paging: 6 months at first, then "Ältere Monate laden". The end marker shows the tracked-since date. Months without tracking are shown compact with "nicht erfasst" and no button.
  • At 360px: highlights stack, the expanded month uses the stacked tiles of the style guide.
  • State "Nicht mehr erfasst": the hint is a friendly in-content card (not a warning banner). Old data stays visible below it.
  • Member shell (all concepts): no drawer. Header = Apollo logo (home), period switch ("Oktober 2026 ▾": running month, past months/years, Benutzerdefiniert) and avatar menu (Privatsphäre, Datenschutz, Abmelden; "Admin" only for admins, leads to the existing admin shell).
  • Menus are <details> here so they work without JS; real pages use MudMenu.
  • Privatsphäre currently links to the existing me-privacy.html; it gets restyled to the chosen concept later.
